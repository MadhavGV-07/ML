P[356]: Appendix C  Code audit notes

P[357]: Feature 13 (illicit-neighbour fraction) uses ground-truth labels of all nodes; feature 14 is random noise.

P[358]: Node label = any incident laundering edge; sampling forces about 25% laundering edges.

P[359]: The reservoir step for normal rows draws random.randint(0, total_scanned), which is not a uniform reservoir over normal rows only; the licit sample is therefore approximately, not exactly, uniform.

P[360]: Edge features are stored but unused by the GNN layers; explanation for GCN, GraphSAGE and MLP uses heuristic influence weights.

P[361]: The web-application default trains for 60 epochs, the benchmark routine for 100 and the engine default is 120; use a single value for reported experiments.

P[362]: The project abstract lists PyTorch Geometric, Pandas, Matplotlib and Jupyter; the application code uses custom PyTorch, NetworkX, NumPy, scikit-learn and Flask, while pandas, seaborn and matplotlib appear only in the EDA notebook.
